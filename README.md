> Lightweight, production-grade in-app network traffic monitoring and API debugging bottom-sheet UI for Android teams and QA engineers.

* **Tech:** Kotlin • MVVM • ViewBinding • BottomSheetDialogFragment • Material Components (M3) • Retrofit
* **Highlights:**

* **Highlights:**
